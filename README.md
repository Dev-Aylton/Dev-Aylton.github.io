# Currículo online

Site estático de currículo e portfólio, feito com HTML, CSS e JavaScript puros.

Para visualizar localmente, abra `index.html` em um navegador.

O currículo para download (`assets/curriculo-aylton-alberto.pdf`) e a imagem de compartilhamento (`assets/portfolio-social.jpg`) são arquivos estáticos. Ao atualizar as informações profissionais, atualize também esses arquivos para manter o PDF e a prévia social em sincronia com o site.
